أريدك أن تعمل كخبير **Senior Frontend / Full Stack (Next.js + App Router + Responsive Navigation + Auth)** وتقوم **بتشخيص وإصلاح مشكلة فعلية** في مشروع **Boioot** بدون تخمين.

## المشكلة الحالية

عند فتح الموقع على **الجوال** بحساب مستخدم مسجل دخول، لا ألاحظ وجود **زر تسجيل الخروج** في الواجهة.

من الصورة الحالية:

* يظهر اسم المستخدم داخل دائرة خضراء
* تظهر أيقونة القائمة الجانبية / الهامبرغر
* لكن **لا يظهر خيار "تسجيل الخروج" بشكل واضح**
* أريد التأكد هل الزر:

  * غير موجود أصلًا؟
  * موجود لكنه مخفي في الموبايل؟
  * موجود داخل القائمة الجانبية ولا يظهر؟
  * مربوط بشرط rendering خاطئ؟
  * أو موجود لكن styling / z-index / responsive logic يمنع ظهوره؟

## المطلوب منك

أريد منك فحص **نظام الـ navigation للموبايل والـ auth menu** بالكامل، ثم حل المشكلة فعليًا.

### 1) افحص الكود الحقيقي المتعلق بهذه الجزئية

راجع الملفات المتعلقة بـ:

* الهيدر الرئيسي
* mobile header
* mobile menu / drawer / sidebar
* user menu / avatar menu
* auth controls
* logout button / logout action
* أي component خاص بالمستخدم المسجل دخوله
* أي شرط rendering مثل:

  * `isAuthenticated`
  * `user`
  * `session`
  * `token`
  * `currentUser`
* أي hook أو store خاص بالمصادقة
* أي action أو API تستخدم لتسجيل الخروج

### 2) شخّص السبب الحقيقي

أريد تقريرًا دقيقًا:

* هل زر تسجيل الخروج موجود أصلًا في نسخة desktop فقط؟
* هل هو مفقود من mobile navigation؟
* هل يوجد menu للمستخدم لكن لا تحتوي على logout؟
* هل يوجد bug في responsive breakpoints؟
* هل الأيقونة أو القائمة لا تفتح كامل العناصر؟
* هل العنصر مخفي بـ CSS؟
* هل هناك مشكلة في App Router أو hydration أو conditional rendering؟

### 3) أصلح المشكلة فعليًا

أريد أن يصبح سلوك الموبايل كالتالي:

#### إذا كان المستخدم غير مسجل

تظهر له بوضوح:

* تسجيل الدخول
* إنشاء حساب

#### إذا كان المستخدم مسجل دخول

يظهر له بوضوح:

* اسمه أو حسابه
* رابط لوحة التحكم أو الحساب إن وجد
* **زر تسجيل الخروج بشكل واضح وسهل الوصول**

### 4) متطلبات UX

أريد الحل يكون احترافيًا على الجوال:

* زر تسجيل الخروج يكون ظاهرًا بوضوح داخل menu المستخدم أو القائمة الجانبية
* لا يكون مخفيًا خلف overflow أو collapsed section
* يكون سهل الضغط على الشاشات الصغيرة
* إذا كان داخل القائمة الجانبية، يكون في مكان منطقي وواضح
* إذا كان داخل user dropdown، تأكد أن الـ dropdown يفتح ويعمل على الموبايل

### 5) تأكد من وظيفة الزر نفسها

بعد إصلاح الظهور:

* تأكد أن زر تسجيل الخروج يعمل فعلًا
* يمسح session / token / auth state
* يعيد المستخدم للحالة العامة الصحيحة
* يحدّث الهيدر بعد logout
* لا يبقى اسم المستخدم ظاهرًا بعد تسجيل الخروج

### 6) راجع النسختين Desktop + Mobile

لا أريد إصلاحًا ينجح على الديسكتوب ويكسر الجوال أو العكس.
تأكد من:

* desktop navigation
* mobile navigation
* user menu
* logout flow

### 7) المطلوب في النهاية

بعد الفحص والإصلاح أعطني:

* السبب الحقيقي
* الملفات التي عدلتها
* ما الذي أصلحته بالضبط
* هل زر تسجيل الخروج أصبح ظاهرًا على الموبايل؟
* وهل logout يعمل فعليًا؟

## مهم جدًا

* لا تعطيني احتمالات عامة
* لا تكتفِ بالشرح
* افحص الكود الفعلي
* نفّذ التعديل بنفسك
* أصلح الظهور والوظيفة معًا

ابدأ الآن من الهيدر والموبايل navigation، ثم تتبع مكان ظهور عناصر المستخدم المسجل دخولًا حتى تصل لسبب اختفاء زر تسجيل الخروج وتصلحه بالكامل.
