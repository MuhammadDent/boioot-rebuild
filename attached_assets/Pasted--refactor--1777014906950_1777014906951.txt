أريد عمل مراجعة وتنظيف شامل للمشروع قبل التشغيل، بدون إضافة ميزات جديدة وبدون refactor كبير.

السياق:
المشروع Boioot Monorepo:
- Frontend: boioot/apps/frontend - Next.js
- Backend: boioot/apps/backend - .NET
- Frontend على Vercel
- Backend على Fly.io
- تم إضافة integrations مثل GA / GTM / Meta / TikTok / Snapchat / Search Console

المطلوب:
اعمل audit شامل وآمن للمشروع بهدف التأكد من صحة الميزات الحالية واستقرار الكود قبل التشغيل.

المهام:

1. فحص عام للكود:
- ابحث عن console.log غير ضرورية
- TODO/FIXME المهمة
- dead code
- imports غير مستخدمة
- ملفات مكررة
- components غير مستخدمة
- أي كود تجريبي أو hardcoded test values

2. فحص integrations:
- تأكد أن Google Analytics لا يسبب duplicate tracking
- تأكد أن GTM محقون مرة واحدة فقط
- تأكد أن Meta / TikTok / Snapchat لا يتم حقنها أكثر من مرة
- تأكد أن كل integration يعمل فقط إذا enabled=true ويوجد ID صالح
- لا تكسر أي integration حالي

3. فحص الصفحات الأساسية:
راجع الصفحات التالية إن وجدت:
- الصفحة الرئيسية
- صفحة تفاصيل العقار/الإعلان
- صفحة نشر إعلان
- تسجيل الدخول
- إنشاء حساب
- لوحة المستخدم
- لوحة الإدارة
- صفحة الباقات
- صفحة طلبات التوثيق
- صفحة integrations
- صفحة الاشتراكات أو الدفع إن وجدت

4. فحص الروابط:
- ابحث عن روابط مكسورة
- href فارغة أو #
- أزرار بدون action واضح
- روابط قديمة أو routes غير موجودة

5. فحص API calls:
- تأكد أن طلبات frontend تستخدم base URL الصحيح
- لا يوجد endpoint قديم أو مكرر
- معالجة 401/403/500 واضحة
- لا يوجد token مطبوع في console

6. فحص Auth:
- تأكد أن صفحات admin محمية
- صفحات المستخدم محمية
- لا يمكن الوصول لصفحات حساسة بدون تسجيل دخول
- عند انتهاء الجلسة تظهر رسالة واضحة

7. فحص UX:
- loading states
- error states
- empty states
- success messages
- عدم وجود أزرار مربكة أو مكررة
- لا تغيّر التصميم جذرياً

8. فحص build:
نفّذ ما يناسب المشروع:
- pnpm lint
- pnpm build
- dotnet build
- أي tests موجودة

9. لا تقم بأي تغيير كبير قبل أن تعرض لي التقرير.
ابدأ أولاً بتقرير Audit فيه:
- المشاكل الحرجة Critical
- المشاكل المتوسطة Medium
- المشاكل البسيطة Low
- توصياتك
- الملفات التي تحتاج تعديل

بعد التقرير، اسألني قبل تنفيذ أي تغييرات كبيرة.

الممنوع:
- لا تضف features جديدة
- لا تغيّر المعمارية
- لا تغيّر database schema
- لا تحذف ملفات بدون سبب واضح
- لا تغيّر UI بشكل كبير
- لا تكسر أي شيء شغال

الهدف:
تنظيف آمن + مراجعة شاملة + تجهيز المشروع للتشغيل production.
