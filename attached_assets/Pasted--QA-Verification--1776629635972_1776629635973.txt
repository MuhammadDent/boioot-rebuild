أريد تنفيذ QA / Verification نهائي واحترافي للمسارات الأساسية بعد آخر تحسينات الأداء والمعمارية.

🔹 مهم جدًا:
في هذه المرحلة لا أريد تحسينات جديدة ولا refactor جديد.
أريد فقط:
- فحص
- تحقق
- اختبار
- تقرير واضح

❌ لا تعدّل الكود إلا إذا اكتشفت bug حقيقي واضح
❌ لا تغيّر UI
❌ لا تغيّر routes
❌ لا تغيّر API
❌ لا تعمل refactor

---

## المطلوب

### 1) فحص المسارات الأساسية التالية

افحص هذه الصفحات بدقة:

- `/`
- `/properties`
- `/properties?listingType=Sale`
- `/properties/[id]` (اختر عقارًا موجودًا فعليًا)
- `/blog`
- `/blog/[slug]` (اختر مقالًا موجودًا فعليًا)
- `/pricing`
- `/login`
- `/register`

---

### 2) تحقق من هذه الأمور في كل صفحة

#### أ) الوظائف الأساسية
- الصفحة تفتح بدون runtime errors
- لا يوجد شاشة بيضاء
- لا يوجد crash
- لا يوجد خطأ واضح في console

#### ب) الاستقرار
- لا يوجد hydration mismatch warnings
- لا يوجد duplicate fetch غير ضروري عند أول تحميل إن أمكن
- لا يوجد loading loop
- لا يوجد flicker واضح في أول الشاشة

#### ج) الـ UI
- layout طبيعي
- لا يوجد كسر تصميم
- لا يوجد عناصر متداخلة أو مفقودة
- الصور تظهر
- الأزرار الأساسية تظهر
- النصوص الأساسية تظهر

#### د) الروابط والتنقل
- الانتقال بين الصفحات يعمل
- الروابط الداخلية تعمل
- route params تعمل
- query params تعمل

---

### 3) فحص خاص للصفحة الرئيسية `/`
تحقق من:
- Hero image تظهر من أول مرة
- لا يحدث تبديل مزعج لصورة Hero بعد hydration
- العنوان والنص والأزرار تظهر بشكل صحيح
- السلايدر يعمل بصريًا
- لا يوجد flicker واضح

---

### 4) فحص خاص لصفحة `/properties`
تحقق من:
- أول النتائج تظهر مباشرة من السيرفر
- query params مثل:
  - `listingType`
  - `page`
  - أي filters موجودة
  تعمل بشكل صحيح
- الفلاتر تعمل
- pagination أو load more يعمل
- لا يوجد hydration warning
- لا يوجد fetch مكرر غير ضروري عند أول تحميل إن أمكن

---

### 5) فحص خاص لصفحة `/properties/[id]`
تحقق من:
- بيانات العقار تظهر من أول تحميل
- أول صورة تظهر
- السلايدر يعمل
- السعر والعنوان والموقع ظاهرين
- أزرار التفاعل مثل:
  - favorites
  - chat
  - phone reveal
  تعمل أو على الأقل تظهر بشكل صحيح
- metadata الأساسية موجودة إن أمكن فحصها

---

### 6) فحص Console / Network
أريدك أن تراجع:
- Console errors
- hydration warnings
- Network requests غير الطبيعية
- هل يوجد duplicate fetch واضح عند أول التحميل في:
  - `/`
  - `/properties`
  - `/properties/[id]`

---

### 7) PageSpeed sanity check
لا أريد optimization جديد، فقط sanity check سريع:

أخبرني هل التحسينات الأخيرة منطقية من ناحية:
- LCP
- initial HTML
- first visible content
- server-rendered data

---

### 8) المطلوب في النهاية
أعطني تقريرًا واضحًا جدًا بهذا الشكل:

#### الصفحات السليمة ✅
- قائمة بالصفحات التي تعمل بشكل طبيعي

#### المشاكل إن وجدت ⚠️
لكل مشكلة:
- الصفحة
- الوصف
- هل هي:
  - بسيطة
  - متوسطة
  - حرجة

#### هل يوجد:
- runtime errors؟
- hydration warnings؟
- duplicate fetch؟
- broken UI؟
- broken routes؟

#### الحكم النهائي
- هل الموقع مستقر الآن بعد التعديلات؟
- هل يمكننا الانتقال للمرحلة التالية؟
- أم يجب إصلاح نقطة محددة أولًا؟

---

## قواعد صارمة
- لا تعدّل شيئًا فقط لأنك "تعتقد" أنه يمكن تحسينه
- لا تقترح تحسينات جديدة الآن إلا بعد إنهاء QA
- إذا كل شيء سليم، قل بوضوح إن الوضع مستقر
- إذا وجدت مشكلة حقيقية، اذكرها بدقة وبأقل تهويل

أريد تقرير QA فقط.
