أريد تحسين أداء الموقع (Frontend فقط) للوصول إلى Performance 90+ في PageSpeed (Mobile) مع التركيز على LCP و Speed Index، بدون كسر أي functionality وبدون تعديل backend أو API.

🔹 السياق:
- المشروع: Boioot (Next.js / React)
- الأداء الحالي جيد لكن:
  LCP ≈ 3.8s (يحتاج تحسين)
  Speed Index ≈ 4.9s
- باقي المقاييس ممتازة (CLS, TBT, SEO, Best Practices)

🔹 الهدف:
تحسين سرعة تحميل أول شاشة (Above the fold) خصوصًا على الموبايل.

---

🔹 المطلوب (نفّذ خطوة بخطوة):

### 1️⃣ تحسين LCP (أهم نقطة)
- حدّد عنصر LCP (غالبًا صورة Hero أو أول صورة إعلان)
- إذا كانت صورة:
  - حوّلها إلى WebP
  - اضبط الحجم ليكون مناسب (لا تستخدم صور ضخمة)
  - أضف:
    loading="eager"
    fetchpriority="high"
  - أضف width و height أو aspect-ratio

- إذا كانت باستخدام Next.js Image:
  - استخدم priority={true}
  - استخدم sizes بشكل صحيح

---

### 2️⃣ تحسين الصور في الموقع كامل
- جميع الصور:
  - lazy loading للصور غير الظاهرة
  - thumbnails صغيرة للقوائم
  - لا تستخدم نفس الصورة الكبيرة في كل مكان
- تأكد من:
  - عدم وجود صور أكبر من المطلوب
  - استخدام WebP أو AVIF

---

### 3️⃣ تحسين السلايدر (Hero / Carousel)
- إذا يوجد سلايدر في أول الصفحة:
  - لا تحمل كل الصور مرة واحدة
  - عطّل autoplay في الموبايل إن كان يسبب ثقل
  - اجعل أول صورة فقط eager والباقي lazy
  - إن أمكن: استبدل السلايدر في الموبايل بصورة واحدة ثابتة

---

### 4️⃣ تقليل render-blocking resources
- أضف defer أو async لكل scripts غير المهمة
- قلل CSS غير المستخدم
- إن أمكن:
  - استخرج critical CSS للأعلى (above the fold)
- لا تمنع render بسبب ملفات JS كبيرة

---

### 5️⃣ تقليل JavaScript غير المستخدم
- استخدم dynamic import لأي components ثقيلة:
  - sliders
  - maps
  - charts
- لا تحمل مكونات غير مستخدمة في الصفحة الرئيسية

---

### 6️⃣ تحسين تحميل الخطوط (Fonts)
- استخدم font-display: swap
- preload للخط الأساسي فقط
- لا تحمل أوزان خطوط غير مستخدمة

---

### 7️⃣ تحسين API loading (بدون تغيير backend)
- لا تنتظر كل البيانات قبل عرض الصفحة
- اعرض skeleton UI أو placeholder سريع
- حمّل البيانات غير المهمة بعد render

---

### 8️⃣ تحسين caching و static assets
- تأكد أن:
  - الصور وملفات JS/CSS لها cache طويل
  - أسماء الملفات تحتوي hash
- لا تعيد تحميل assets في كل مرة

---

### 9️⃣ الحفاظ على:
❌ لا تغيّر UI
❌ لا تغيّر routes
❌ لا تغيّر backend
❌ لا تكسر رفع الصور أو الإعلانات

---

🔹 المطلوب في النهاية:
- قائمة بالتعديلات التي قمت بها
- قبل/بعد (LCP و Performance إذا أمكن)
- أي ملفات تم تعديلها

🔹 مهم:
نفّذ التعديلات بشكل incremental وآمن بدون refactor كبير.
