أريدك أن تعمل كخبير **Senior Full Stack (Next.js + ASP.NET Core + Pricing/Subscriptions UX)** وتقوم **بتشخيص وإصلاح مشكلة فعلية** في مشروع **Boioot** بدون تخمين.

## المشكلة الحالية

في صفحة **الباقات / الاشتراكات**، يتم عرض كروت الباقات مثل:

* مجاني للمالك
* أساسي للمالك
* وغيرها

لكن **لا توجد صفحة أو واجهة واضحة لعرض تفاصيل الباقة** قبل اختيارها.

حاليًا المستخدم يرى اسم الباقة والسعر وبعض المعلومات المختصرة فقط، لكن لا يوجد:

* صفحة تفاصيل باقة
* أو مودال تفاصيل
* أو قسم موسع يشرح المزايا والقيود بشكل واضح

وهذا يسبب ضعفًا في تجربة المستخدم، لأن المستخدم لا يعرف تفاصيل ما سيختاره.

## المطلوب منك

أريد منك فحص **نظام عرض الباقات بالكامل** ثم تنفيذ حل احترافي فعلي.

### 1) شخّص الحالة الحالية بدقة

افحص الكود الحقيقي الخاص بصفحة الباقات:

* هل توجد أصلًا صفحة تفاصيل لكل باقة لكنها غير مربوطة؟
* هل يوجد route مفقود؟
* هل يوجد زر "اختر الباقة" فقط بدون "عرض التفاصيل"؟
* هل توجد البيانات الكاملة للباقات في backend لكن لا يتم عرضها؟
* هل يوجد component ناقص أو UX غير مكتمل؟
* هل الباقات مبنية من static config أم من API؟

### 2) افحص الملفات الفعلية المتعلقة بهذه الجزئية

راجع الكود الحقيقي في:

* صفحة الباقات / الاشتراكات
* أي components تعرض subscription cards / pricing cards
* أي route أو page خاص بالاشتراكات
* أي API أو endpoint يجلب الباقات
* أي config أو constants تحتوي مزايا الباقات
* أي منطق مرتبط بزر:

  * اختر الباقة
  * اشترك
  * عرض التفاصيل
* أي صفحة دفع أو checkout مرتبطة بالباقة

### 3) نفّذ حلًا احترافيًا

أريد إضافة **طريقة واضحة لعرض تفاصيل الباقة** قبل اختيارها.

يمكنك اختيار أفضل حل هندسي حسب بنية المشروع، لكن يجب أن يكون احترافيًا وواضحًا. مثلًا أحد هذه الخيارات:

* صفحة مستقلة لكل باقة
* أو مودال تفاصيل
* أو accordion/collapsible details داخل نفس الصفحة
* أو drawer على الجوال

لكن يجب أن يكون الحل:

* واضحًا للمستخدم
* مناسبًا للجوال والديسكتوب
* سهل الوصول
* غير مربك

### 4) ما الذي يجب أن يظهر في تفاصيل الباقة

أريد أن تتضمن تفاصيل الباقة بوضوح:

* اسم الباقة
* الفئة المستهدفة
* السعر
* مدة الاشتراك
* عدد الإعلانات المسموح
* المزايا الرئيسية
* القيود
* هل الباقة مناسبة لمالك فردي أم مكتب أم شركة
* أي معلومات مهمة قبل الشراء

### 5) تحسين UX

أريد تحسين تجربة صفحة الباقات بحيث:

* لا يضطر المستخدم لاختيار باقة بدون فهمها
* يوجد زر واضح مثل:

  * عرض التفاصيل
  * تفاصيل الباقة
  * معرفة المزيد
* إذا كانت هناك باقة حالية للمستخدم، يظهر ذلك بوضوح
* وإذا كانت الباقة الحالية معروضة، يمكن رؤية تفاصيلها أيضًا
* لا يتم كسر flow اختيار الباقة أو الدفع

### 6) راجع الربط مع الاختيار والدفع

إذا ضغط المستخدم:

* **عرض التفاصيل** → يرى التفاصيل فقط
* **اختر الباقة** → يكمل flow الاشتراك/الدفع

تأكد من عدم الخلط بين الزرين.

### 7) المطلوب في النهاية

بعد الفحص والتنفيذ أعطني:

* ما الحالة الحالية فعليًا؟
* هل كانت صفحة التفاصيل مفقودة أم فقط غير مربوطة؟
* ما الملفات التي عدلتها؟
* ما الذي أضفته أو أصلحته؟
* وهل أصبح بإمكان المستخدم رؤية تفاصيل كل باقة بوضوح على الجوال والديسكتوب؟

## مهم جدًا

* لا تعطيني شرحًا عامًا
* لا أريد احتمالات فقط
* افحص الكود الفعلي
* نفّذ التعديل بنفسك
* اجعل الحل احترافيًا ومناسبًا لتجربة المستخدم

ابدأ الآن من صفحة الباقات الحالية، ثم تتبع طريقة عرض الباقة واختيارها، ونفّذ إضافة عرض تفاصيل الباقة بشكل واضح ومتكامل.
