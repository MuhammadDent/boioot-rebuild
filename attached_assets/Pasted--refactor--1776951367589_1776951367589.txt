أريد إظهار تقييم العقار على بطاقة الإعلان في صفحات القوائم قبل فتح صفحة العقار، بدون refactor كبير وبدون كسر الأداء.

## الوضع الحالي

* داخل صفحة تفاصيل العقار، التقييم يظهر بشكل صحيح
* لكن في بطاقات العقارات داخل:

  * الصفحة الرئيسية
  * صفحة الإيجار اليومي
  * أي listing/cards view
    لا تظهر درجة التقييم على الكرت

## المطلوب

أريد أن يظهر على كرت العقار:

* متوسط التقييم (مثلاً 3.8)
* وعدد التقييمات (مثلاً 1 تقييم أو (1))
* فقط إذا كان للعقار تقييمات فعلية
* وإذا لا يوجد تقييمات، لا تظهر مساحة فارغة مزعجة

## المطلوب تقنيًا

1. افحص الـ listing endpoints / DTOs / queries التي تغذي بطاقات العقارات في:

   * home page
   * daily rentals listing
   * property cards / listing cards

2. تحقق هل هذه endpoints ترجع أصلًا:

   * `averageRating`
   * `ratingsCount`
     أو أي fields مكافئة مثل:
   * `ratingAverage`
   * `reviewCount`
   * `ratingSummary`

3. إذا لم تكن موجودة:

   * أضفها بأقل تغيير ممكن وبشكل performant
   * استخدم نفس منطق summary الصحيح المستخدم في صفحة تفاصيل العقار
   * تجنب N+1 query قدر الإمكان
   * يفضل جلب summary ضمن query/DTO الخاص بالlisting أو عبر join/aggregation مناسبة

4. إذا كانت القيم موجودة من backend لكن لا تظهر:

   * عدّل frontend card component فقط لعرضها بشكل clean
   * حافظ على UI الحالي
   * لا تزحم الكرت
   * اجعل العرض متناسقًا مع صفحة التفاصيل
   * مثال مناسب:

     * ⭐ 3.8
     * (1)
       أو
     * 3.8 ★ · 1 تقييم

5. اجعل السلوك كالتالي:

   * إذا `ratingsCount > 0` → اعرض التقييم
   * إذا `ratingsCount == 0` أو null → لا تعرض قسم التقييم

6. بعد التنفيذ:

   * اعطني الملفات التي عدلتها
   * هل كان النقص من backend أم frontend أم الاثنين
   * ثم نفّذ:

     * `git add .`
     * `git commit -m "feat: show property rating summary on listing cards"`

## مهم جدًا

* لا تغيّر صفحة التفاصيل
* لا تعمل refactor واسع
* لا تكسر performance في صفحات القوائم
* لا تضف dummy values
* أريد نفس rating truth المعتمد في صفحة العقار، لكن ظاهر أيضًا على بطاقة الإعلان
