أريد تحويل نظام المدن والأحياء إلى نظام ديناميكي ذكي يعتمد على مساهمات المستخدمين بشكل مباشر.

المطلوب:

========================
أولاً: الإضافة المباشرة
=======================

عند قيام أي مستخدم بإضافة:

* مدينة جديدة
  أو
* حي جديد

يجب:

1. إضافته مباشرة إلى قاعدة البيانات بدون انتظار موافقة الأدمن.
2. يصبح متاحاً فوراً لجميع المستخدمين في جميع الفورمات والقوائم.
3. أي مستخدم آخر يفتح نفس المحافظة أو المدينة يجب أن يرى العناصر المضافة سابقاً.

========================
ثانياً: نظام منع التكرار الذكي
==============================

أريد بناء نظام normalization + duplicate detection ذكي.

قبل إضافة مدينة أو حي جديد:
يقوم النظام بفحص:

* الأحرف العربية المختلفة:
  ة / ه
  أ / ا / إ / آ
  ى / ي
* إزالة المسافات الزائدة
* إزالة الرموز
* تجاهل حالة الأحرف
* trim
* مقارنة fuzzy بسيطة

أمثلة:
"جرمانا"
"جرمانه"
" جرمانا "
يجب اعتبارها متشابهة.

========================
ثالثاً: الاقتراح التلقائي
=========================

إذا كتب المستخدم اسماً قريباً من اسم موجود:

لا يتم إنشاء مدينة جديدة مباشرة.

بدلاً من ذلك:
يعرض النظام اقتراحاً مثل:

"هل تقصد: جرمانا؟"

ويعطيه خيار:

* استخدام الاسم الموجود
* المتابعة وإضافة اسم جديد

========================
رابعاً: نظام الثقة
==================

أضف حقل:
isVerified

للمدن والأحياء.

* المدن الرسمية التي يضيفها الأدمن:
  isVerified = true

* المدن التي يضيفها المستخدمون:
  isVerified = false

لكن كلاهما يظهران للمستخدمين.

========================
خامساً: تحسين البحث والقوائم
============================

في أي Select أو Search للمدن والأحياء:

1. أظهر النتائج الرسمية أولاً.
2. ثم النتائج المضافة من المستخدمين.
3. دعم البحث أثناء الكتابة.
4. دعم autocomplete.
5. دعم الترتيب حسب الأكثر استخداماً.

========================
سادساً: التعميم على كامل المنصة
===============================

هذا النظام يجب أن يعمل في:

* نظام المطابقة
* إنشاء الإعلانات
* تغطية المكاتب
* الإيجار اليومي
* البحث
* الفلاتر
* أي فورم يحتوي مدينة أو حي

ولا أريد منطقاً منفصلاً لكل صفحة.

========================
سابعاً: قواعد مهمة
==================

1. لا تستخدم hardcoded lists.
2. اجعل النظام reusable.
3. لا تكسر البيانات الحالية.
4. تأكد أن "كل المدن" لا يتم التعامل معها كمدينة حقيقية.
5. لا تسمح بإنشاء آلاف التكرارات لنفس الاسم بصيغ مختلفة.

========================
ثامناً: المطلوب بعد التنفيذ
===========================

بعد التنفيذ أعطني:

* الملفات المعدلة
* الجداول الجديدة أو الحقول الجديدة
* آلية duplicate detection المستخدمة
* أمثلة على حالات تم اختبارها
* كيف يتم ترتيب النتائج
* كيف يعمل autocomplete
