أريد إضافة صفحة جديدة احترافية في موقع Boioot باسم:
"المكاتب والوسطاء"

الهدف:
عرض المكاتب العقارية والوسطاء العقاريين على شكل كروت مشابهة لفكرة كروت الإيجار اليومي، بحيث يستطيع الزائر مشاهدة معلومات المكتب أو الوسيط والتواصل معه.

مهم جداً:
لا تلمس production backend أو production database.
استخدم بيئة التطوير المحلية فقط حسب إعدادات العزل الحالية:
BACKEND_URL=http://localhost:8080
Database=Helium/local
ولا تستخدم fly.dev أو boioot.net API أثناء التطوير.

المطلوب:

1) إنشاء صفحة عامة جديدة:
Route:
/agencies

العنوان:
المكاتب والوسطاء

وصف الصفحة:
تصفح المكاتب والوسطاء العقاريين المعتمدين وتواصل معهم مباشرة.

2) إضافة رابط في النافبار:
"المكاتب والوسطاء"

ويكون قابل للإخفاء والإظهار لاحقاً من إعدادات الموقع مثل باقي الأقسام.

3) تصميم الكروت:
كل كرت مكتب/وسيط يحتوي على:
- شعار المكتب أو صورة الوسيط
- اسم المكتب أو الوسيط
- نوع الحساب: مكتب عقاري / وسيط عقاري
- المدينة / المنطقة
- رقم التقييم إن وجد
- عدد الإعلانات المنشورة
- نبذة قصيرة
- زر "مراسلة"
- زر "عرض الملف"
- رابط واتساب إن وجد
- حالة التوثيق إن وجدت: موثق / غير موثق

4) صفحة تفاصيل المكتب/الوسيط:
Route:
/agencies/[id]

تعرض:
- الشعار
- الاسم
- نوع الحساب
- المدينة
- نبذة تعريفية
- بيانات التواصل المسموحة
- زر مراسلة
- إعلاناته المنشورة
- تقييماته إن وجدت مستقبلاً

5) لوحة تحكم الأدمن:
أضف قسم داخل لوحة الأدمن باسم:
"المكاتب والوسطاء"

يتيح للأدمن:
- عرض قائمة المكاتب والوسطاء
- إظهار أو إخفاء مكتب/وسيط من الصفحة العامة
- تمييزه كـ موثق
- تمييزه كـ مميز
- تعديل النبذة
- تعديل المدينة
- رفع أو تعديل الشعار
- ترتيب الظهور إن أمكن

6) لا تجعل المكاتب تظهر تلقائياً إذا لم يوافق الأدمن.
أضف حقل:
isVisible
أو
isPublic

وحقل:
isVerified

وحقل:
isFeatured

7) مصدر البيانات:
ابدأ باستخدام المستخدمين الموجودين الذين نوعهم:
- RealEstateOffice
- Broker
أو الأسماء الموجودة فعلياً في النظام لأنواع الحسابات.

لا تنشئ نظام مستخدمين جديد.
اربط الصفحة بالمستخدمين الحاليين.

8) في حال عدم وجود مكاتب:
اعرض Empty State احترافي:
"لا توجد مكاتب أو وسطاء متاحون حالياً"
وزر:
"تصفح العقارات"

9) أضف فلترة:
- حسب المدينة
- حسب النوع: مكتب / وسيط
- موثق فقط
- مميز فقط

10) اجعل التصميم متوافقاً مع RTL والموبايل.

11) لا تكسر أي صفحات حالية.
لا تغير منطق تسجيل الدخول أو الإعلانات أو الطلبات.

12) بعد التنفيذ:
اعطني:
- الملفات المعدلة
- هل تم إضافة route جديد
- كيف أختبر الصفحة
- كيف أتحكم بها من لوحة الأدمن

ولا تعمل commit ولا push.
