أريد تعديل لوحة تحكم الأدمن في Boioot لإضافة إمكانية إدارة حذف المستخدمين بشكل احترافي وآمن، بدون كسر أي وظائف موجودة.

المطلوب تحديداً:

1. في صفحة:
 /dashboard/admin/users
أضف زر واضح باسم:
"حذف"
لكل مستخدم داخل كرت المستخدم.

2. لا تسمح بحذف المستخدم مباشرة عند الضغط.
يجب إظهار نافذة تأكيد قبل الحذف تحتوي على:
- اسم المستخدم
- البريد الإلكتروني
- تحذير واضح أن الإجراء سيؤدي إلى إخفاء/حذف الحساب من النظام
- زرين: "إلغاء" و "تأكيد الحذف"

3. لا تستخدم Hard Delete إذا كان المستخدم مرتبطاً ببيانات أخرى مثل:
- إعلانات
- طلبات
- محادثات
- توثيق
- اشتراكات
- سجلات دخول

استخدم Soft Delete كخيار آمن:
- إضافة حقل في جدول المستخدمين مثل:
deletedAt أو isDeleted
- عند الحذف يتم تحديث هذا الحقل فقط
- لا يتم حذف السجلات المرتبطة من قاعدة البيانات

4. بعد حذف المستخدم:
- لا يظهر في قوائم المستخدمين العادية
- لا يستطيع تسجيل الدخول
- يتم إخفاء إعلاناته وطلباته العامة من الواجهة
- تبقى بياناته محفوظة للأدمن والسجلات

5. أضف فلتر في لوحة الأدمن لعرض:
- المستخدمون النشطون
- المستخدمون المحذوفون / المؤرشفون
- الكل

6. في حالة المستخدم المحذوف، أظهر Badge واضح:
"محذوف" أو "مؤرشف"

7. أضف زر:
"استعادة"
للمستخدمين المحذوفين فقط، بحيث يعيد الحساب إلى الحالة النشطة بإزالة deletedAt أو تغيير isDeleted إلى false.

8. امنع حذف حساب الأدمن الحالي لنفسه.
إذا حاول الأدمن حذف حسابه، أظهر رسالة خطأ واضحة:
"لا يمكنك حذف حسابك الحالي"

9. امنع حذف آخر حساب Admin في النظام.
يجب التحقق من ذلك في backend وليس frontend فقط.

10. أضف API endpoint آمن خاص بالأدمن فقط لتنفيذ الحذف والاستعادة.
يجب التحقق من صلاحية الأدمن من جهة السيرفر.

11. أضف Toast notifications واضحة:
- تم حذف المستخدم بنجاح
- فشل حذف المستخدم
- تم استعادة المستخدم بنجاح
- لا يمكنك حذف حسابك الحالي

12. لا تغيّر تصميم الصفحة بالكامل.
المطلوب إضافة الوظيفة فقط مع الحفاظ على نفس أسلوب التصميم الحالي.

13. قبل تنفيذ أي تعديل:
افحص بنية قاعدة البيانات الحالية، علاقات المستخدمين، وأسماء الجداول والحقول المستخدمة فعلياً.
لا تفترض أسماء الجداول إذا كانت مختلفة.

14. بعد التنفيذ:
اختبر الحالات التالية:
- حذف مستخدم عادي
- حذف مكتب عقاري
- حذف وسيط
- محاولة حذف حساب الأدمن الحالي
- محاولة حذف آخر Admin
- استعادة مستخدم محذوف
- التأكد أن المستخدم المحذوف لا يستطيع تسجيل الدخول
- التأكد أن إعلاناته لا تظهر للعامة

نفذ التعديل بأقل تغييرات ممكنة، وبطريقة آمنة وقابلة للرجوع، ولا تلمس أي وظائف غير مرتبطة بإدارة حذف المستخدمين.
