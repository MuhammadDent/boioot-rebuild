أريد تبسيط نظام إدارة الباقات (Plans) وإزالة التعقيد الحالي بدون كسر أي جزء من النظام.

## 🎯 الهدف

إزالة التكرار والتضارب بين:

* نوع الحساب (Account Type)
* فئة الخطة (Plan Category)

والاعتماد فقط على:

* الجمهور المستهدف (Audience)
* المستوى (Tier)

---

## ⚠️ قواعد صارمة (يجب الالتزام بها)

1. ❌ لا تقم بأي refactor كبير
2. ❌ لا تغيّر backend logic أو database schema
3. ❌ لا تحذف أي أعمدة من قاعدة البيانات
4. ❌ لا تكسر أي API أو routes
5. ❌ لا تغيّر شكل البيانات القادمة من السيرفر
6. ✅ التعديل يكون في **Frontend فقط (UI/UX)**

---

## 🧹 المطلوب (Frontend فقط)

### 1) إزالة الحقول التالية من واجهة الإدارة:

* حقل: "نوع الحساب المستهدف"
* حقل: "فئة الخطة"

❗ ملاحظة:

* لا تحذفها من الكود نهائيًا إذا كانت مستخدمة
* فقط أخفها من UI (hide/remove from form)

---

### 2) الإبقاء فقط على الحقول التالية:

#### A. هوية الخطة

* الاسم العربي
* الاسم الإنجليزي
* الوصف

#### B. من هذه الخطة؟

* الجمهور المستهدف (Audience)

#### C. مستوى الخطة

* المستوى (Tier)

---

### 3) ترتيب الفورم بشكل واضح

رتب الحقول بهذا الشكل:

1. معلومات أساسية
2. الجمهور المستهدف
3. المستوى
4. التسعير
5. الحدود
6. الميزات
7. الهوية البصرية

---

### 4) إضافة توضيح UX بسيط

تحت "الجمهور المستهدف" أضف نص صغير:

"حدد لمن هذه الخطة (مالك، مكتب، شركة...)"

---

### 5) التعامل مع القيم المخفية

إذا backend يحتاج:

* accountType
* category

قم بما يلي:

* عيّنها تلقائيًا بدون إظهارها للمستخدم

مثال:

```
if (audience === "owner") accountType = "Individual"
if (audience === "office") accountType = "Office"
if (audience === "company") accountType = "Company"
```

---

### 6) لا تغيّر API

* استمر بإرسال نفس الحقول
* فقط لا تجعل المستخدم يختارها

---

### 7) تنظيف الكود

* احذف أي UI غير مستخدم متعلق بـ:

  * Plan Category
  * Account Type selector

لكن:

* لا تحذف enums أو types من backend

---

## 🧪 التحقق بعد التنفيذ

تأكد من:

1. يمكن إنشاء خطة بدون أي أخطاء
2. لا يظهر أي حقل مكرر أو مربك
3. لا يوجد console errors
4. يتم إرسال البيانات بشكل صحيح للـ API
5. الباقات تظهر بشكل طبيعي في صفحة الاشتراكات

---

## 📋 المطلوب في الرد

أعطني تقرير مختصر:

* ما الذي تم إزالته من UI؟
* كيف تم تعويض accountType؟
* هل يوجد أي جزء ما زال مكرر أو غير واضح؟

---

## 🚫 ممنوع

* لا تضف Features جديدة
* لا تغيّر naming في backend
* لا تعيد تصميم كامل الصفحة

---

## الهدف النهائي

واجهة نظيفة + بدون تكرار + سهلة للإدارة
