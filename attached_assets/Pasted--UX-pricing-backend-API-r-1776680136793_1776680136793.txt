أريد تحسين تجربة المستخدم UX في صفحة الباقات `/pricing` بشكل احترافي، بدون تغيير backend أو API أو routes.

🔴 مهم جدًا:
- لا refactor كبير
- لا تغيير API
- لا تغيير منطق الاشتراك
- لا تغيير database
- التعديل فقط في UI / presentation / UX

---

## الهدف

تحويل صفحة الباقات من صفحة "عرض عادي" إلى صفحة:
- واضحة جدًا
- مقنعة
- سهلة الفهم
- تدفع المستخدم لاتخاذ قرار

---

## المطلوب

### 1) إزالة أي Loading غير ضروري
- إذا المستخدم غير مسجل:
  ❌ لا تنتظر `/api/dashboard/subscription/current`
  ✅ اعرض الباقات مباشرة

- إذا المستخدم مسجل:
  اعرض الباقات + حالته الحالية (إن وجدت)

---

### 2) تحسين عرض الباقات (Cards)

لكل باقة:

- اسم الباقة (واضح وكبير)
- السعر (بارز جدًا)
- المدة (شهري / سنوي)
- قائمة المميزات

---

### 3) تحسين عرض السعر

بدل:
100

اجعلها:
100 ريال / شهريًا

أو:
100 SAR / month

ويكون السعر:
- أكبر عنصر بصري في الكارد
- bold + واضح

---

### 4) إبراز باقة واحدة (Recommended)

اختر باقة (مثلاً الوسطى) واجعلها:

- border مميز
- background خفيف
- badge:
  ⭐ الأكثر طلبًا

---

### 5) زر CTA واضح

لكل باقة:

- زر:
  "اشترك الآن"
  أو
  "ابدأ الآن"

---

### 6) حالات المستخدم

#### إذا المستخدم غير مسجل:
- الضغط على الزر → يوجه إلى `/login`

#### إذا المستخدم مسجل:
- يظهر:
  - "باقة الحالية"
  - أو:
  "ترقية"
  "تجديد"

---

### 7) Empty / Edge cases

إذا API فشل:
- لا تترك الصفحة فارغة
- اعرض الباقات بشكل طبيعي

---

## ممنوع

- لا تغيير backend
- لا تغيير API
- لا تغيير routes
- لا إضافة مكتبات جديدة
- لا تغيير logic الاشتراك

---

## قبل التنفيذ
أعطني:
1. ما الملفات التي ستعدلها
2. ما التغييرات UX المقترحة باختصار

ثم نفّذ مباشرة

---

## بعد التنفيذ
أعطني:

1. الملفات المعدلة
2. ماذا تغير في UI
3. هل تغير أي شيء في backend؟ (يجب: لا)
4. هل الصفحة تعمل لغير المسجل؟ (يجب: نعم)
5. هل الصفحة تعمل للمسجل؟ (يجب: نعم)

---

## اختبار إلزامي

- افتح `/pricing` بدون تسجيل:
  - لا spinner
  - تظهر الباقات فورًا

- افتح `/pricing` بعد تسجيل:
  - تظهر حالة الاشتراك

- لا runtime errors
