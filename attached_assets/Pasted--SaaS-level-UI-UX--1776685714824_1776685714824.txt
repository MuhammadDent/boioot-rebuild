أريد إعادة تنظيم شاشة "إنشاء/تعديل الباقات" في لوحة الإدارة بشكل احترافي (SaaS level UI/UX) بدون كسر أي شيء في backend أو تغيير API أو database.

🎯 الهدف:
تبسيط النظام + تقليل التعقيد + تحسين تجربة مدير النظام.

---

🧠 أولاً: إعادة هيكلة الشاشة (UI Structure)

قسّم الشاشة إلى 5 أقسام فقط بهذا الترتيب:

1) Basic Info (المعلومات الأساسية)
2) Pricing (التسعير)
3) Limits (الحدود)
4) Features (المميزات)
5) Advanced Settings (إعدادات متقدمة - collapsed افتراضيًا)

---

🟢 1. Basic Info

انقل فقط هذه الحقول هنا:
- اسم الخطة
- الوصف
- فئة الخطة
- نوع الحساب المستهدف
- Tier
- لون الخطة
- Badge
- ترتيب العرض

لا تضف أي منطق جديد.

---

🟡 2. Pricing (تبسيط جذري)

بدل النظام الحالي:

أنشئ field واحد فقط:

Plan Type:
- Free
- OneTime
- Subscription

---

🧠 Mapping مهم (بدون تغيير backend):

- إذا اختار Free:
  → لا تظهر أسعار

- إذا OneTime:
  → billingCycle = OneTime
  → أظهر حقل سعر واحد فقط

- إذا Subscription:
  → أظهر:
    - Monthly price
    - Yearly price

---

❗ استخدم نفس API الحالية:
IsCycleCompatible + billingCycle + prices
لكن اخفِ التعقيد من UI

---

🔵 3. Limits (تبسيط كامل)

❌ أزل الاعتماد على "كتالوج الحدود" من واجهة المستخدم

✅ اعرض الحقول مباشرة:

- عدد الإعلانات النشطة
- عدد الصور لكل إعلان
- عدد الفيديوهات لكل إعلان
- عدد الرسائل
- عدد المشاريع
- عدد الإعلانات المميزة

---

🧠 إذا كان backend يعتمد على keys:
اعمل mapping داخلي فقط بدون تغيير API

---

🟣 4. Features (تنظيف)

اعرض فقط features المهمة كـ toggles:

- رفع فيديو
- لوحة التحليلات
- دعم فني بأولوية
- ظهور في الصفحة الرئيسية
- شارة موثّق
- واتساب مباشر
- إعلانات مميزة

---

❌ لا تعرض features غير معرفة في catalog
❌ لا تعرض disabled items

---

⚙️ 5. Advanced Settings (Collapsed)

ضع داخل Accordion مغلق:

- الفترة التجريبية
- قواعد الاشتراك التجاري
- سياسة الاستهلاك
- إعدادات الدفع
- downgrade / upgrade logic

---

🎯 UX Improvements:

- قلل عدد الأقسام الظاهرة
- استخدم spacing واضح
- group كل قسم داخل Card واضح
- أضف Icons بسيطة لكل section
- اجعل النموذج readable خلال 5 ثواني

---

🚫 ممنوع:

- لا تغير API
- لا تغير backend logic
- لا تحذف أي field من payload
- فقط UI + mapping

---

🎁 Bonus (مهم):

- أضف summary صغير أعلى الفورم:
  يظهر:
  نوع الخطة + السعر + أهم limit

---

🎯 النتيجة المتوقعة:

- شاشة نظيفة
- سهلة الفهم
- تقليل الأخطاء
- جاهزة للتوسع مستقبلاً
