أريد تنفيذ نظام احترافي للتحكم بإظهار وإخفاء أقسام الموقع من لوحة تحكم الأدمن Feature Toggles / Site Sections Visibility.

المشروع هو Boioot وفيه Frontend Next.js و Backend .NET.

المطلوب:

1) أضف نظام إعدادات عام للموقع في قاعدة البيانات باسم مناسب مثل:
AppSettings / SiteSettings / FeatureFlags

يجب أن يحتوي على مفاتيح مثل:
- section_projects_enabled
- section_requests_enabled
- section_daily_rent_enabled
- section_blog_enabled

كل مفتاح يكون Boolean true/false.

2) أنشئ Backend API عام للفرونت:
GET /api/settings/public

يرجع فقط الإعدادات العامة اللازمة للواجهة مثل:
{
  "sectionProjectsEnabled": true,
  "sectionRequestsEnabled": true,
  "sectionDailyRentEnabled": true,
  "sectionBlogEnabled": true
}

3) أنشئ Backend API خاص بالأدمن فقط:
GET /api/admin/settings
PUT /api/admin/settings

يجب أن يكون محمي بصلاحيات الأدمن فقط.

4) في لوحة تحكم الأدمن أضف صفحة جديدة باسم:
إعدادات الموقع

وفيها Toggle Switch لكل قسم:
- عرض قسم المشاريع
- عرض قسم الطلبات
- عرض قسم الإيجار اليومي
- عرض المدونة

مع زر حفظ واضح، وليس حفظ تلقائي.

5) عند الضغط على حفظ:
- يتم إرسال القيم إلى PUT /api/admin/settings
- تظهر رسالة نجاح واضحة
- لا ترجع القيم تلقائياً إلى التعطيل بعد الحفظ
- أعد تحميل القيم من السيرفر للتأكد من حفظها

6) في الواجهة العامة:
استخدم هذه الإعدادات لإخفاء أو إظهار روابط النافبار:
- المشاريع
- الطلبات
- الإيجار اليومي
- المدونة

مثلاً إذا section_projects_enabled = false:
- لا يظهر رابط المشاريع في النافبار
- ولا تظهر أي أزرار مرتبطة بالمشاريع في الصفحة الرئيسية إن وجدت

7) حماية مهمة:
لا تعتمد فقط على إخفاء الرابط من الفرونت.
إذا حاول المستخدم الدخول مباشرة إلى /projects والقسم معطل:
- اعرض صفحة لطيفة تقول: هذا القسم غير متاح حالياً
أو أعد توجيهه للرئيسية.
ونفس الشيء لباقي الأقسام.

8) لا تكسر أي ميزة موجودة.
لا تحذف صفحات أو Routes.
فقط اجعل ظهورها مشروطاً بالإعدادات.

9) استخدم أسماء واضحة للكود، وتعامل مع القيم الافتراضية:
إذا لم تكن الإعدادات موجودة في قاعدة البيانات، أنشئها تلقائياً بقيم true حتى لا تختفي الأقسام فجأة.

10) بعد التنفيذ:
- اعرض لي ملخص الملفات التي تم تعديلها
- وضح كيف أختبر الميزة خطوة بخطوة
- لا تعمل commit ولا push إلا بعد موافقتي.
