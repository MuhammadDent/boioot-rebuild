أريد تحسين Approval Flow للحجوزات في لوحة المالك بشكل احترافي، بإضافة خيار ثالث بين القبول والرفض وهو: "طلب تعديل".

السياق:
حاليًا توجد إجراءات:
- قبول
- رفض

لكن هذا غير كافٍ، لأن بعض الحالات لا تستحق الرفض النهائي، بل تحتاج فقط إلى تصحيح أو إعادة رفع مستند أو إضافة ملف ناقص.

المطلوب:

1) إضافة إجراء جديد في بطاقة الحجز للمالك:
- زر: "طلب تعديل"
- يكون بجانب "قبول" و "رفض"

2) عند الضغط على "طلب تعديل":
- افتح inline panel أو modal صغيرة داخل البطاقة
- تحتوي على:
  - textarea لكتابة ملاحظة المالك
  - زر "إرسال طلب التعديل"
  - زر "إلغاء"

3) تعليق المالك يجب أن يكون إجباريًا:
- لا يمكن إرسال طلب التعديل بدون كتابة سبب واضح
- أظهر validation message عربية مناسبة:
  "يرجى كتابة سبب طلب التعديل"

4) Backend / state flow:
- أضف حالة جديدة للحجز مخصصة لطلب التعديل
- استخدم اسمًا واضحًا ومتناسقًا مع النظام الحالي مثل:
  RevisionRequested
  أو NeedsChanges
- لا تكسر الحالات الحالية

5) عند إرسال طلب التعديل:
- احفظ:
  - الحالة الجديدة
  - تعليق المالك
  - تاريخ الطلب إن أمكن
- ثم حدّث البطاقة مباشرة في الواجهة بدون refresh كامل

6) في واجهة المستأجر:
- إذا كانت الحالة "طلب تعديل"
- أظهر badge واضحة مثل:
  "مطلوب تعديل"
- واعرض تعليق المالك أسفلها داخل صندوق واضح
- مثال:
  "ملاحظة المالك: الرجاء رفع إثبات دفع أوضح لأن الصورة الحالية غير واضحة"

7) اسمح للمستأجر بعد ذلك بـ:
- رفع مستند جديد
- إعادة إرسال إثبات الدفع
- مع بقاء تعليق المالك ظاهرًا حتى تتم إعادة الإرسال أو تتغير الحالة

8) UX / UI:
- استخدم نفس أسلوب التصميم الحالي
- اجعل زر "طلب تعديل" بلون تحذيري مناسب (amber/orange مثلًا)
- textarea تكون واضحة ومنسقة
- أظهر loading state أثناء الإرسال
- أظهر toast نجاح:
  "تم إرسال طلب التعديل بنجاح"
- وأظهر toast خطأ مناسب عند الفشل

9) مهم:
- فرّق بوضوح بين:
  - رفض نهائي
  - طلب تعديل
- لا تجعل "طلب تعديل" يعامل كرفض

10) أريد تنفيذًا clean وآمنًا:
- بدون كسر flow الحالي
- بدون refactor كبير غير ضروري
- مع تحديث الواجهة في جهة المالك والمستأجر

في النهاية أريد:
- شرح مختصر للملفات التي عُدلت
- ما هي الحالة الجديدة التي تمت إضافتها
- كيف يظهر التعليق للمالك والمستأجر
