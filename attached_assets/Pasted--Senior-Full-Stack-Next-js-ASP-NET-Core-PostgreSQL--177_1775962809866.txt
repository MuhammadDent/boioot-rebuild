أريدك أن تعمل كخبير **Senior Full Stack (Next.js + ASP.NET Core + PostgreSQL)** وتقوم **بتشخيص وإصلاح مشكلة فعلية** في مشروع **Boioot** بدون تخمين.

## المشكلة الحالية

أنا الآن داخل صفحة **إضافة إعلان إيجار يومي**.

عند فتح نموذج إضافة الإعلان:

* أضغط زر **+** لإضافة **مدينة جديدة**
* أو أضغط زر **+** لإضافة **حي جديد**
* تظهر نافذة منبثقة بشكل صحيح
* أكتب الاسم
* ثم أضغط **حفظ**

**لكن لا يتم حفظ المدينة أو الحي**، ولا يظهر العنصر الجديد داخل القائمة المنسدلة.

## المطلوب منك

أريد منك أن تقوم بالعمل التالي **خطوة بخطوة**:

### 1) تشخيص دقيق للمشكلة

افحص كامل الـ flow الخاص بإضافة:

* مدينة جديدة
* حي جديد

وابحث تحديدًا في هذه النقاط:

* هل زر **حفظ** يستدعي `onSubmit` أو `onClick` فعلًا؟
* هل المودال مربوط بشكل صحيح بالـ state؟
* هل الطلب يرسل إلى الـ API أم لا؟
* هل يوجد خطأ validation يمنع الإرسال؟
* هل يوجد exception صامت في frontend؟
* هل يوجد خطأ من backend؟
* هل الـ request يصل لكن يفشل؟
* هل يتم الحفظ في قاعدة البيانات لكن لا يتم تحديث القائمة؟
* هل هناك مشكلة في `refresh`, `refetch`, أو إعادة تحميل بيانات المدن/الأحياء بعد الحفظ؟
* هل الحفظ يحتاج authentication أو token غير موجود؟
* هل يوجد mismatch بين أسماء الحقول المرسلة من frontend وما يتوقعه backend؟

### 2) افحص هذه الأجزاء فعليًا

أريدك أن تراجع الكود الحقيقي المتعلق بـ:

* صفحة إضافة الإعلان اليومي
* كومبوننت اختيار المدينة
* كومبوننت اختيار الحي
* المودال الخاص بإضافة مدينة
* المودال الخاص بإضافة حي
* أي service / api client / axios / fetch خاص بالمدن والأحياء
* أي endpoint في ASP.NET Core مسؤول عن:

  * إنشاء مدينة
  * إنشاء حي
  * جلب المدن
  * جلب الأحياء
* الـ DTOs / request models / validation
* الـ DbContext / migrations إذا لزم

### 3) نفّذ التشخيص عمليًا

أريدك أن:

* تحدد **السبب الحقيقي** للمشكلة
* لا تعطيني احتمالات عامة
* أضف logs مؤقتة إذا احتجت
* راقب Console errors
* راقب Network requests
* تحقق من response status و response body
* تحقق من backend logs إذا كان الطلب يصل

### 4) أصلح المشكلة بالكامل

بعد اكتشاف السبب:

* عدّل الكود المطلوب
* أصلح الحفظ للمدينة والحي
* تأكد أنه بعد الضغط على **حفظ**:

  1. يتم إنشاء المدينة/الحي بنجاح
  2. يغلق المودال
  3. يتم تحديث القائمة المنسدلة مباشرة
  4. يتم اختيار العنصر الجديد تلقائيًا إن أمكن
  5. تظهر رسالة نجاح واضحة
  6. تظهر رسالة خطأ واضحة إذا فشل الحفظ

### 5) راجع تجربة المستخدم UX

حسّن السلوك ليكون احترافيًا:

* تعطيل زر الحفظ أثناء الإرسال
* إظهار loading state
* منع الحفظ إذا كان الاسم فارغًا
* منع التكرار إن كان الاسم موجودًا مسبقًا
* إظهار رسالة مفهومة للمستخدم بدل الفشل الصامت

### 6) مهم جدًا

* لا تكتفِ بالشرح
* **نفّذ التعديل فعليًا في الملفات**
* ثم أعطني في النهاية:

  * ما هو السبب الحقيقي؟
  * ما الملفات التي عدلتها؟
  * ما الذي أصلحته بالضبط؟
  * وهل المشكلة أصبحت محلولة بالكامل؟

## ملاحظة

المشكلة موجودة في **إضافة إعلان إيجار يومي**، وبالتحديد في حفظ:

* مدينة جديدة
* حي جديد

ابدأ الآن بفحص الكود الحقيقي المتعلق بهذه الجزئية، ثم أصلحها مباشرة.
