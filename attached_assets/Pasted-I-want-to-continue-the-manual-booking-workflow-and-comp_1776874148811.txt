I want to continue the manual booking workflow and complete the next production-safe phase in my Boioot project.

Current status:

* Booking creation works successfully
* `POST /api/bookings` returns 201
* initial booking status is `PendingApproval`
* booking retrieval endpoints were fixed and now work
* we are intentionally postponing the PropertyId type cleanup until after this workflow is stable

Now I want to implement the **owner approval + payment proof + final confirmation** flow cleanly.

## Goal

Complete this booking lifecycle:

1. Tenant creates booking request
   -> `PendingApproval`

2. Owner reviews request and can:

   * Approve initially
   * Reject

If approved:
-> `ApprovedAwaitingPaymentProof`

3. Tenant uploads payment proof images/files + optional note
   -> `PaymentProofSubmitted`

4. Owner reviews proof and can:

   * Confirm booking finally
   * Reject proof / reject booking

If confirmed:
-> `Confirmed`

If rejected:
-> `Rejected`

---

# Backend requirements

## 1) Booking statuses

Make sure these statuses are fully supported end-to-end:

* PendingApproval
* ApprovedAwaitingPaymentProof
* PaymentProofSubmitted
* Confirmed
* Rejected

Do not add unnecessary extra statuses unless required.

---

## 2) Endpoints to implement/update

### Owner initial approve

POST `/api/bookings/{id}/approve`

Rules:

* only owner of the property can do this
* only allowed when status = `PendingApproval`
* set status to `ApprovedAwaitingPaymentProof`
* set `ApprovedAt`

### Owner reject

POST `/api/bookings/{id}/reject`

Rules:

* only owner
* allowed from:

  * PendingApproval
  * PaymentProofSubmitted
* set status to `Rejected`

### Tenant submit payment proof

POST `/api/bookings/{id}/submit-proof`

Payload:

* uploaded file(s) or image URL(s), depending on existing upload architecture
* optional note

Rules:

* only tenant who created the booking
* only allowed when status = `ApprovedAwaitingPaymentProof`
* store:

  * payment proof references
  * payment note
  * `PaymentProofSubmittedAt`
* set status to `PaymentProofSubmitted`

### Owner final confirm

POST `/api/bookings/{id}/confirm`

Rules:

* only owner
* only allowed when status = `PaymentProofSubmitted`
* set status to `Confirmed`
* set `ConfirmedAt`
