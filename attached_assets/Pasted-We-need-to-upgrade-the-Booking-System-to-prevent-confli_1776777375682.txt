STEP 2 — Prevent Double Booking (CRITICAL)

Before creating booking:

Check:
If ANY existing booking exists for same property where:

- status = Confirmed
AND
- date overlap:

(startDate < existing.EndDate AND endDate > existing.StartDate)

→ Reject request
