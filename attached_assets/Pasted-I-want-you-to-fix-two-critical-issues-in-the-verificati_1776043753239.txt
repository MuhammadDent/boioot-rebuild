# 🔴 Issue 1: Cannot upload additional documents

* First document uploads successfully
* When trying to upload a second document:

  * It gets rejected
  * Sometimes shows "Invalid document type"
  * No clear reason for rejection
  * No proper user feedback

Users should be able to:

* Upload **multiple documents**
* Add documents one by one
* See validation errors clearly (if any)

---

## 🔍 What you need to check (Root Cause Analysis)

Investigate:

1. Frontend:

   * Is the file input being reset after first upload?
   * Is state blocking additional uploads?
   * Is validation incorrectly triggered?
   * Is FormData reused incorrectly?

2. Backend:

   * Does the API allow multiple documents per request?
   * Is there a restriction like "only one document per type"?
   * Is validation rejecting duplicates incorrectly?
   * Is file type detection wrong (MIME vs extension)?

3. API:

   * Endpoint: POST /api/verification/requests/{id}/documents
   * Does it overwrite instead of append?
   * Does it return proper error messages?

  * size
  * duplicate (if applicable)

### C) Fix UI behavior

* Reset file input after upload
* Show success message after upload
